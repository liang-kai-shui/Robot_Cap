# P4：静态世界扰动与独立真值评分

日期：2026-10-06（北京时间）。基于 P3 的 `da55e04`，继续在 `v1-runtime-hardening` 开发；不合并 `main`，不修改原 `task/benchmark_tasks.py`。本轮零付费模型请求，暂不实现 Policy reuse。

## 本轮改动

- 增加可选 `PerturbedVirtualBackend`：物理几何使用真实位姿，导航 API 返回独立的里程计估计。私有真值和真实事件不注册为能力。
- 对当前前向测距注入有界均匀误差、丢读和样本过期；对动作注入移动/转向偏差、可取消等待；对定位注入距离比例误差和初始位姿偏移。
- `RangeObservation` 增加 `uncertainty_m`，地图更新、规划与 guard 都使用测距下界；动作请求再按已声明的最大移动增益收缩。
- P4 在停稳时最多重采样 2 次，每次计入累计观测预算。无效/过期样本记录在 `rejected_samples`，不更新地图，不进入动作决策。连续失败安全结束；guard 仍在每次前进前独立重新采样。
- 增加独立评测 CLI、可复现实验清单、逐次结果、代码签名检查和续跑。默认模拟器、原能力、旧路径及旧评分保持兼容。

执行链保持：目标顺序 → 持续导航 → 单调用 Python → Validator → Worker → Proxy → Runtime → guard → Backend。没有增加机器人 API、ROS、数据库或硬件驱动依赖。

## 借鉴现有实现

参考 [Nav2 状态估计文档](https://docs.nav2.org/rolling/getting_started/navigation_concepts/state_estimation/) 中里程计估计与全局修正的职责：本项目先明确估计状态和评分真值，尚未加入全局定位修正。

参考 [Nav2 障碍层文档源码](https://github.com/ros-navigation/docs.nav2.org/blob/rolling/docs/configuration_and_development/configuration_guide/core_servers/costmap_2d/costmap_plugins/obstacle.md) 对观测更新时效的处理：当前轻量实现检查样本年龄和有效性，不引入 ROS；地图占用老化和动态障碍处理留待后续。

这是针对现有项目的实现取舍，上游项目的实验成绩不作为本项目成绩。

## 实验方法

### 固定任务

原 H1–H4 与 P3 M1–M6，共 10 题；11 个工况，每题每工况 3 个种子，共 330 个 episode。任务顺序由 reference oracle 提供，实际动作仍只依赖局部观测，不接收障碍物地图。

| 工况 | 注入参数 |
|---|---|
| ideal | 无扰动 |
| range-3cm | 测距误差均匀分布 ±0.03 m，声明相同误差界限 |
| dropout-5pct | 每次测距独立有 5% 概率无效 |
| age-250ms | 样本时间戳回溯 0.25 s |
| stale-2500ms | 样本时间戳回溯 2.5 s，超过 2 s 时效要求 |
| move-8pct | 实际移动距离为请求值的 0.92–1.08 倍 |
| turn-08deg | 实际转角为请求转角加均匀 ±0.8° |
| odometry-3pct | 里程计记录的移动距离为实际距离的 1.03 倍 |
| offset-20cm | 初始估计 x 比真值大 0.2 m，后续不做全局修正 |
| delay-20ms | 每个移动/转向动作前真实等待 0.02 s，支持取消 |
| combined | 测距 ±0.03 m，丢读 2%，移动 ±5%，转角 ±0.5°，里程计 +1% |

故障基础种子 `20261006`；每个任务/重复的种子为 `seed + task_index*10000 + repeat`。同一任务重复跨工况共享种子，但传感器与动作各用独立随机流。导航路径分叉后，相同随机序列不代表物理位置仍能逐次配对。

### 新随机地图

冻结实现后，使用地图种子 `161803` 生成 30 个新静态可达世界，每个运行 ideal、range-3cm、move-8pct、odometry-3pct、combined 五个工况，共 150 个 episode；故障基础种子 `20261007`。地图由原生成器采样，连通性检查仅供私有评测，导航不调用该检查。开发时使用另一套小规模故障种子；未根据这批新地图成绩调参数。

### 公共设置与评分

各工况统一最多 80 个动作、160 次导航观测；0.25 m 栅格、0.15 m 余量、1.5 m 最大前进请求、2 s 样本时效、0.25° 转向容差、停稳后最多 2 次重采样。已声明的测距误差界限与动作增益界限可用于 guard；未知里程计偏差不提供给规划器。guard 的额外读数单独记入 `sensor_samples`，与原导航一致，不消耗导航观测预算。

在本静态模型和声明界限成立的条件下，允许的前进请求为 `min(max_step, (测距下界 - margin) / 最大执行增益)`。动作前 guard 读取新的样本；如果新距离更短会拒绝旧规划。误差下界只是保守距离，不是定位修正，累积地图仍可能因位姿漂移而出错。

所有正式 episode 使用真实 `spawn` Worker。基准只检验导航执行与防护，不重新评测 LLM 的任务理解。`total_ms` 包含 Worker 和本地开销；虚拟几何动作依然是瞬时提交，不是实车运行时间。两套正式实验并行运行，墙钟耗时受本机负载影响，不能直接与上一批模型延迟比较。

- `reported_completion`：导航根据估计位姿确认所有目标完成。
- `actual_mission_success`：任务报告完成且执行成功，私有真值按顺序在目标容差内停稳、最终成功条件成立、没有碰撞尝试。
- `false_completion`：报告完成，但上述真实几何条件不成立。即使最终目标对了，中途漏停也算误报。
- `safe_abort`：未报告完成，最终停稳且无碰撞尝试。这是安全结束，不是任务成功。

机器可读汇总保留实验清单和逐次指标。完整公开 episode、私有真值轨迹、地图与运行日志保留在本地 `runs/p4-static-formal/`、`runs/p4-unseen-formal/`。

## 结果

### 固定任务：330 次

| 工况 | 真实完成 | 报告完成 | 误报完成 | 安全中止 | 碰撞尝试 |
|---|---:|---:|---:|---:|---:|
| ideal | 30/30 | 30 | 0 | 0 | 0 |
| range-3cm | 30/30 | 30 | 0 | 0 | 0 |
| dropout-5pct | 29/30 | 29 | 0 | 1 | 0 |
| age-250ms | 30/30 | 30 | 0 | 0 | 0 |
| stale-2500ms | 0/30 | 0 | 0 | 30 | 0 |
| move-8pct | 30/30 | 30 | 0 | 0 | 0 |
| turn-08deg | 29/30 | 29 | 0 | 1 | 0 |
| odometry-3pct | 21/30 | 30 | 9 | 0 | 0 |
| offset-20cm | 0/30 | 27 | 27 | 3 | 0 |
| delay-20ms | 30/30 | 30 | 0 | 0 | 0 |
| combined | 29/30 | 30 | 1 | 0 | 0 |

330 次均最终停稳。stale-2500ms 全部在移动前拒绝读数，30 次安全中止是预期的负对照。offset-20cm 的 3 次安全中止均为 H4 动作预算耗尽；另外 27 次虽报告到达，真实位置没有完成任务。

dropout-5pct 共遇到 28 次丢读、16 次停稳重采样、11 次动作前 guard 拒绝，29 次任务完成；另一次连续无效读数超过有限重试后安全结束。turn-08deg 有一次 M2 转向校正达到停滞保护，安全结束。组合组虽全部报告完成，但有一次真实终点未达到要求。

### 新随机地图：150 次

| 工况 | 真实完成 | 报告完成 | 误报完成 | 安全中止 | 碰撞尝试 |
|---|---:|---:|---:|---:|---:|
| ideal | 30/30 | 30 | 0 | 0 | 0 |
| range-3cm | 30/30 | 30 | 0 | 0 | 0 |
| move-8pct | 30/30 | 30 | 0 | 0 | 0 |
| odometry-3pct | 3/30 | 27 | 24 | 3 | 0 |
| combined | 27/30 | 30 | 3 | 0 | 0 |

150 次均最终停稳，无碰撞尝试。3% 里程计组的三个安全中止均为动作预算耗尽；不是已经证明目标不可达。组合组含 1% 里程计误差，所以“误差较小”仍不等于满足终点容差。

例如 R001 的里程计组：估计最终位置 `(9.27260, 8.24873)`，真实位置 `(9.21369, 8.11770)`，定位误差 **0.14366 m**。导航报告到达，但真值没有在目标容差内停稳，评分记为误报。该案例的真值仅用于事后判定，没有反馈给导航。

全部逐次指标和代码签名见 [机器可读汇总](navigation_robustness_p4_summary.json)。

### 判断与实车意义

有界测距和移动误差下，现有观测闭环能完成本批全部任务；有限重采样可恢复多数短暂丢读，但不会无限重试。持续过期样本能在移动前被拒绝。

**位置估计的系统性偏差仍会让“完成”失真。** 固定任务的 3% 里程计组真实完成 21/30，而新随机地图仅 3/30；这些结果不能按地图规模直接作因果归因，但足以说明不能用理想定位成绩代替实车可靠性。降低模型调用频率不会解决这一问题。

本轮完成了误差防护与评分改进，没有实现任意漂移下的可靠全局导航。下一轮应先解决可观测的定位与完成确认，再增加动态环境或视觉能力。

## 物理适用边界

1. 数值是压力测试参数，未用你的 6 V N20 电机、Hall 编码器、43/65 mm 轮子或 ToF 校准；不能声称对应实际器件精度。
2. 当前角度反馈准确反映实际模拟转角；没有陀螺仪偏置、编码器量化或左右轮独立运动模型。
3. 单束距离来自已考虑安全足迹的配置空间。真实 ToF 还需要原始量程、姿态、安装偏移、有效性和足迹适配；误差界限未知时不能沿用本实验的安全证明。
4. 世界是静态矩形几何；碰撞检测拒绝整段移动，`collision_attempt` 是碰撞尝试，不模拟撞击过程。没有运动中的持续检测、惯性或刹车距离。
5. 样本过期由时间戳回溯实现，并非模拟 transport 阻塞；20 ms 动作等待是实际等待，不代表真实移动耗时。等待循环每 5 ms 内检查取消，几何提交使用短内存锁，未声称能硬杀 Python 线程或物理 I/O。
6. 导航目前无法仅靠里程计与前向单束距离修正任意初始全局坐标偏移。真值评分能揭露误判，不会自动把真实位置提供给导航。
