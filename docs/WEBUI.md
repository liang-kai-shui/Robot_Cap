# 小车 WebUI 使用说明

这是运行在电脑本机的 Robot CaP 控制台。网页负责显示和交互，Python 服务沿用现有 Runtime、Policy 校验和 ESP32 串口后端。v1.8 / PARAM1 兼容控制功能；测距、轮速和3D姿态回传需要2026-10-12的新遥测固件，本次已更新用户的COM5开发板。

## v1.9 更新

持续按住控制、测距接近、按距离后退、开机上下文、错误诊断和自动执行选项见 [完整更新说明](ROVER_V19.md)。新动作需v1.9/PARAM2；本页以下旧步进路径仍可切换使用。设置中的“编译并烧录v1.9”要求先断开网页串口、拔下电机5V、只保留USB并勾选确认。

## 双击启动

在项目根目录双击 **Start_Robot_UI.vbs**，浏览器会打开 `http://127.0.0.1:8765`。启动器优先使用这台电脑已有的 ESP-IDF Python 环境，也支持项目 `.venv`。不用打开 PowerShell，不用安装 Node.js。

默认只启动网页服务，不自动连接串口或执行动作。再次双击会打开已经运行的控制台。

1. 关闭旧键盘控制程序和 IDF 串口 monitor，让 COM5 空闲。
2. 小车静止，接好 USB 和电机独立电源。在页面上方的“连接小车”区域选择实际串口（例如 COM5 — Silicon Labs CP210x），点击“连接设备”。
3. 显示固件版本和“已停稳，待命”后，可以使用手动控制。
4. 自然语言任务需要打开“模型与设置”，输入 API Key。默认 DeepSeek / deepseek-flash；密钥只留在服务进程内存中，不写浏览器存储或运行记录。
5. 输入任务，点击“生成计划”。默认查看校验后的动作，再点击“执行计划”；也可勾选自动执行。反馈和耗时会回传到网页。

顶部“断开设备”关闭串口；设置中的“结束服务”退出后台服务。关闭网页不会退出后台服务，正在执行的任务会因页面离开或失联而停止。结束服务后可再次双击启动。

若 Python 环境没有项目依赖，先安装一次：`python -m pip install -e ".[hardware]"`。找不到 Python 时，启动器会提示；可修改启动器里的 Python 路径，或建立可用的项目 `.venv`。

## 工作台区域

| 区域 | 用途与读数含义 |
| --- | --- |
| 设备概览 | 固件、连接状态、硬件位置示意；图中的车不是相机画面。 |
| 姿态回传 | BMI323 横滚、俯仰、相对转角、校准和有效性；相对转角不是绝对航向。 |
| 左右轮距离 | 最近移动动作停止后的编码器估计，单位 mm；不代表真实地面位移。 |
| 曲线 | 收到的相对转角采样；旧数据标注过期，新版固件在运动期间也持续回传。 |
| 前方距离 | VL53L1X 距离（cm / mm）、光学状态、总线错误和更新时间。无效、过期或未初始化时不显示虚构距离。 |
| 车速与车轮 | 编码器增量除以实际采样时间；按左右轮独立标定系数换算 cm/s，再按 43 mm 轮径换算 rpm。车体纵向估计取左右轮均值。 |
| BMI323 3D | Three.js 渲染传感器板，按 Roll / Pitch / 相对 Yaw 计算姿态四元数，可拖动观察、缩放和复位视角。安装轴向未标定，不代表绝对航向。 |
| 手动控制 | 前进 5/10/20/30 cm，左右转 15/30/45/90°；后退每次固定0.8秒。取消持续模式时每次点击执行有界动作；默认按住W/S/A/D持续控制、松开停车。 |
| 自然语言 | 先校验再执行；最多 9 次运动，每段最多 3 次，段间停稳后默认本地检查，可切换模型审核。 |
| 当前任务 | 阶段、总耗时、模型请求、执行和反馈审核耗时；180 秒条表示时间预算，不是行程百分比。 |
| 任务记录 | 分页卡片、动作预览、生成代码和筛选，可下载JSON；同开机重连保留上下文，设备重启/服务重启清空。 |
| 终端与回传 | 串口原始日志、任务事件、构建输出，可筛选、暂停显示、清屏和下载。 |

测距采集已经启用；前方停车保护仍为 **OFF**，v1.9的approach动作独立按测距闭环，普通前进和手动遥控不启用该保护。未接入的数据（地面定位、相机、电池电压等）不会生成虚构读数。

轮子小动画跟随实际编码器计数，对每个回传间隔做平滑插值，不靠指令或固定时间持续旋转。数据失效/过期时停止动画。减弱动态效果设置会使用直接更新。3D 视图也只更新有效姿态，失效时冻结，画面数字显示无效状态。地面打滑、安装方向和线材拖拽会影响显示与真实运动的对应关系。

2026-10-12 的测距/轮速/姿态显示需要新版遥测固件（协议仍为 v1.8/PARAM1，READY 新增 `tof=ON`）。旧固件显示“采集关闭”或等待轮速/3D 回传，需要更新固件。3D 引擎和控制模块本地提供；浏览器不支持 WebGL 时仍可查看姿态数字和轮子动画。

勾选“键盘控制”后，W 前进、S 后退、A/D 左右转、T 停止，Esc 中止；按住键不会重复排队，输入框内不会触发运动。后退固定0.8秒，前进步长选择不用于后退。后退使用已有固件的S指令，等待左右轮编码器结果、DONE和新的停稳READY；失败或中止后不重试。后方没有测距。

后退属于可信手动控制，尚未向自然语言Policy开放，不能当作“后退指定厘米”的接口。上下文会记录实际手动后退，避免后退后继续引用更早的转向任务。

## 内嵌终端

这是机器人命令终端，可以完成连接、状态、控制、计划和构建；不是任意 PowerShell 系统 shell。

| 命令 | 用途 |
| --- | --- |
| `help` / `status` / `ports` | 帮助、设备状态、串口列表 |
| `connect COM5` / `disconnect` | 连接或断开 |
| `move 0.10` | 前进 0.10 米，等待停稳 |
| `turn 30` / `turn -30` | 左转 / 右转 30°，等待停稳 |
| `back` | 手动后退0.8秒，等待停稳 |
| `stop` / `t` | 停止；Ctrl+C 也可停止 |
| `plan 前进10厘米，然后左转30度` | 生成并预览计划 |
| `run` | 执行已校验的计划 |
| `build` | 设备断开时编译固件，输出显示在网页；不烧录 |

按钮、终端和自然语言任务共用同一后端，不互相抢串口。一次只执行一个任务，另一页面不能接管仍在执行的动作。停止按钮始终可用。

执行期间点击停止、页面关闭或心跳超过约 4 秒，会取消剩余动作。运动中止或后端故障后需要显式重新连接，不重试运动。网页停止不能代替断电措施；服务自身退出或电脑故障时应使用已有固件停止机制。

## 固件构建

“固件构建”用固定的本机 ESP-IDF 5.1.2 环境编译 `firmware/esp32s3`，输出送到终端。构建前先断开设备。页面不提供刷写，已有 v1.8 / PARAM1 无需刷写。

## 离线演示与开发入口

双击 **Preview_Robot_UI.vbs**，在 `http://127.0.0.1:8766` 体验演示设备。页面持续标注演示，传感器和动作均模拟，模型使用本地规则，不连接硬件、不请求 API。

从项目根目录也可以运行：

```bash
python web_control.py --open
python web_control.py --demo --port 8766 --open
```

`--port` 是网页 HTTP 端口，设备串口在页面选择。服务只监听本机 `127.0.0.1`，不向局域网开放。

如果页面显示“离线演示”且只提供 DEMO，说明打开了 8766 演示入口，它不能连接实车。双击 Start_Robot_UI.vbs，使用 8765 实车控制台。“连接小车”区域显示已发现的串口和设备名称；没有设备时会明确提示接 USB 数据线后刷新，不自动打开串口。

运行记录在 `runs/webui/latest-session.json`，默认不上传 GitHub；保存近期事件和状态，不是完整历史数据库。密钥会被隐藏，分享前仍应检查任务内容。

## 实现与验证

- `web_control.py`：启动入口。
- `webui/controller.py`：控制权、任务、停止、计时、上下文、回传解析。
- `webui/server.py`：本机 HTTP / SSE、来源和令牌检查。
- `webui/static/`：本地 HTML、CSS、JavaScript，无 CDN 和前端构建依赖。
- `webui/demo.py`：隔离的演示设备和模型。
- `tests/test_webui.py`：假串口、取消、心跳、分段、来源和密钥隐藏测试。

软件验证使用假串口和离线演示，真正的小车仍需用户连接，核对网页回传与动作。演示通过不代表实车已经验证。

设计参考 [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，控制与日志分区参考 [Foxglove Teleop](https://docs.foxglove.dev/docs/visualization/panels/teleop) 和 [Log](https://docs.foxglove.dev/docs/visualization/panels/log)。方案见 [WEBUI_DESIGN](WEBUI_DESIGN.md)，协议见 [SERIAL_PROTOCOL](SERIAL_PROTOCOL.md)。
