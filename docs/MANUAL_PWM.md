# 手动 PWM 滑块（pwm-stream-v1）

手动面板提供 **0–100% 实际 PWM 占空比**，步长 1%，每次打开页面默认 40%。100% 对应驱动输出的最大占空比，没有隐藏的 60% 映射。PWM 是供电通断的比例，不等于电机转速百分比；转速受负载、摩擦和供电影响。

连接支持 `teleop_pwm=1` 的新固件后，在“持续按住模式”下调节滑块，再按住方向按钮或 W/A/S/D。按住期间的调节随下一次心跳更新；松开、失焦、通道断开或调到 0 都停止。0 不发送运动帧。页面显示固件回传的左右轮占空比；等待回传时显示横线。

此模式直接设置两轮 PWM，不做速度 PI 和 BMI 航向保持，因而不会要求有效 BMI 才能手动前后行走。编码器方向、无边沿、超速、控制周期以及 BOOT/T 停止检查仍保留。很低的占空比可能不能克服摩擦，并触发无边沿停止。250ms 失联停止和单次连续按住最多 30s 的限制不变，PWM 更新不会延长最大按住时间。

取消持续模式后，滑块不可调；步进动作及自然语言 CaP 的距离、转角、测距接近继续使用原闭环控制和传感器要求。模型没有手动 PWM API。旧固件可继续原来的遥控，但滑块禁用并提示烧录。

## 固件和协议

版本保持 v1.9/PARAM2，构建标记为 `pwm-stream-v1`。READY 增加 `build=pwm-stream-v1 teleop_pwm=1`。

新帧 `@U<session*10000+direction*1000+percent>\n`：session 为 1–99999；direction 为 1前、2后、3左、4右；percent 为 1–100。例如 `@U11040\n` 表示第 1 次按住、前进、40%。0 使用 T 停止。更换方向需要释放后重新按住，过期 session 不能重新启动。

UART 是字节流，读一次可能包含几个心跳或下一个心跳的一部分。解析器允许同一次按住、同方向、同模式的续租合并，采用最后一个完整 PWM 值；不同动作、方向、session 或模式混合仍拒绝。有限距离/角度指令不合并、不排队，T 始终优先。此修复针对可在离线测试复现的连读问题，不代表解决全部传感器故障。

更新前拔下电机独立 5V，只保留开发板 USB，断开控制台串口后烧录。重新连接后检查新构建标记。固件更新后的实际运动需要用户验证；开发验证不做堵转或电流测试。
