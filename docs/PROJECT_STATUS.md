## 实车当前边界

- 当前已烧录固件：v1.9 / PARAM2 / `pwm-stream-v2`；PC兼容旧v1.8/PARAM1。连接使用UART0串口，构建标记与协议号分开记录。
- CaP前进/后退5–30cm，左右转15–90°，固定速度策略；v1.9另开放前方净距10–100cm的approach及只读测距/姿态。新增运动能力仍待用户地面验证。
- WebUI默认人工按住控制，松开停车；手动PWM直接设占空比、不做BMI航向保持，闭环动作保留原速度与传感器检查。步进手动后退仍固定0.8秒；模型没有连续遥控或直接PWM权限。
- 普通任务最多3个运动+STOP；分段任务最多9个运动，每段最多3个，整项180秒。
- WebUI默认本地审核每段有效停稳反馈，可切换模型CONTINUE/ABORT；不做路线重规划、临时纠偏或失败动作重试。
- 按用户最新请求，ToF采样已启用并显示于WebUI；前方停车保护仍OFF。车速、左右轮动画和BMI323的3D姿态使用回传数据，不是独立地面测量。
- 编码器距离和相对陀螺仪角度是估计量；无独立地面位姿、绝对航向、地图或碰撞真值。
- `execution_success`说明代码/反馈流程完成；实车`task_success=null`，不使用模拟评分器证明真实到达。

## 最新用户测试

2026-10-13 调研优化后重新运行完整离线测试，521项通过（严格警告模式）。C控制逻辑检查和`pwm-stream-v2`完整编译已通过；最近固件烧录后的停止握手、双轮零速、BMI及ToF静止回传正常。以下两段任务结果是此前的用户实测，不把上述软件检查计入实车成功率。

指令：“前进10厘米，左转30度，右转30度，再前进10厘米，最后停止”。两段都返回完成并确认停稳；整项约22.732秒。两次前进的最终编码器均值为115.1/110.2mm，左右转的相对角度为33.1/−31.9°。未提供独立地面测量，不能据此声称厘米级定位精度。

此前“原地转半圈”因单次180°超范围被拒绝，“分两次转”因方向和每次角度不明确被拒绝；期间出现HTTP402余额不足，未执行动作，随后新的人为请求成功。完整记录边界见[实车报告](../reports/physical_integration_2026-10-12.md)。
